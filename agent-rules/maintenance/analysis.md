# 공통 패턴 추출 기록

정리일: 2026-10-04. 규칙 정리/감사 때만 읽는다. 일상 작업의 필수 로딩 대상이 아니다.

## 범위와 방법

제공된 원문 묶음(이하 `<원문루트>`)의 루트 MD 10개와 `rules/` MD 19개를 대상으로 공통 요구·금지·사용자 정정·검증 기록을 추출하고 핵심 문맥을 대조했다. 루트 진입 문서·공통 작업 원칙을 읽고, 주제 파일은 제목·규칙·정정·관련 문맥을 선별 검토했다. 도메인별 전체 구현을 감사한 작업은 아니다.

`rules.zip` 내부 MD 19개와 디스크 `rules/`의 SHA-256이 모두 일치했다. 따라서 압축본을 별도 복제하지 않고 같은 내용의 디스크 문서를 분석했다. 원문은 수정하지 않았다.

원문에서 참조하는 `rules/99_정리이력_및_미해결.md`, `admin.md`는 제공 경로에 없었다. 내용은 추정하지 않았으며 그 문서까지 검토했다고 주장하지 않는다.

## 충돌·범위 처리

- 옛 색인의 petite-vue 설명과 최신 문서의 Vue 설명 충돌: 특정 프레임워크를 공통화하지 않고 실제 파일 확인으로 일반화.
- 옛 Maven 빌드/SSO 일회성 절차와 최신 `.run` 우선 규칙 충돌: 해당 프로젝트 실행 정의 우선 원칙만 추출.
- Up이면 정상이라는 옛 설명과 로그+UI 확인 요구 충돌: Up만으로 기능 성공 판정 금지로 통합.
- PPT 빌드 스크립트 정본이라는 옛 절과 원본 직접 편집 우선 절 충돌: 최신 원본과 직접 수정분 보존을 채택. 팔레트·좌표·특정 라이브러리는 제외.
- 공유 상태 메모리 금지와 파드별 캐시 갱신 사례: 공유 업무 상태와 로컬 캐시를 구분하는 조건부 규칙으로 통합.
- 과거 파일 로그 접근 금지는 최신 정정으로 폐기. 특정 MCP/로그 경로는 공통 규칙에서 제외.
- “새 파일 금지”는 임의 신설 금지로 정리. 이번 문서 생성과 향후 요청된 프로젝트 구현을 막는 절대 금지로 확대하지 않음.
- 단계별 전문 에이전트/외부 메신저 보고는 기존 환경의 운영 방식이므로 자동 위임·자동 전송의 공통 의무로 옮기지 않음.
- 테이블·컬럼·코드값·전화번호·벤더·발급/배송 업무·포트·절대 경로·다중 파드 고정 수량은 프로젝트 전용으로 제외.
- 과거 조사·실측·성공 메모는 날짜가 있는 근거이며 현재 환경이나 보편적 사실로 승격하지 않음.
- 긴 사고 사례·취소선 누적 대신 실행 문서에는 최신 결론만 두고 이 기록에 정리 판단을 남김.
